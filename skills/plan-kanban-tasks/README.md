# Plan Kanban Tasks

Turn an approved product requirement into a concise PDR and implementation-sized YYLO Ledger tasks with explicit scope, dependencies, acceptance criteria, and validation ownership.

## Install

```bash
npx skills add yylo-dev/yylo-skills --skill plan-kanban-tasks
```

This skill plans or registers work; it does not grant implementation, publication, or deployment authority. Read [`SKILL.md`](SKILL.md) for the complete contract.
