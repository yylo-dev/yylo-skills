# Ralph Loop

Execute exactly one explicitly assigned YYLO Ledger task through discovery, an isolated task worktree, focused validation, a clean commit, preflight, and queue submission.

## Install

```bash
npx skills add yylo-dev/yylo-skills --skill ralph-loop
```

The skill includes supporting references and a Ledger command wrapper. It must be invoked explicitly for an assigned task. Read [`SKILL.md`](SKILL.md) for the complete contract.
