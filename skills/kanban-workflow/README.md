# Kanban Workflow

Use this skill when an agent needs to inspect or mutate tasks through YYLO Ledger. It documents task creation, status changes, search, dependencies, ordering, archival, and controller-safe routing.

## Install

```bash
npx skills add yylo-dev/yylo-skills --skill kanban-workflow
```

The skill expects a compatible `yy`/`yylo-ledger` command in the working environment. Read [`SKILL.md`](SKILL.md) for the complete operating contract.
